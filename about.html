About the Interactive Loot Map

A free, community-focused research project for Days Gone.

Roadmap

Project phases

  1. Phase 1 — Recording end-game loot. Documenting and checking every piece of loot available in the end game.
  2. Phase 2 — Fresh-playthrough loot. Recording loot from a fresh-playthrough perspective, adding missions, and detailing mission-specific loot spawns.
  3. Phase 3 — UI and future features. Improving the UI and building future features. Everything currently added is intended as WIP functionality.
